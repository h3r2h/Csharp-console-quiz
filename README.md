# C# Console Quiz Game

A multi-round, interactive console quiz application built in C# to demonstrate core programming logic, modular design, and data structure manipulation.

## 🚀 Features
- **Modular Architecture:** Utilizes the DRY (Don't Repeat Yourself) principle with a generic `RunRound` engine to handle multiple categories seamlessly.
- **Data Structures:** Manages questions, options, and answers using 2D arrays (`string[,]`) and parallel arrays.
- **Robust Input Validation:** Ensures application stability by handling invalid user inputs gracefully using `int.TryParse` and strict range checking (`1-4`).
- **File I/O Integration:** Automatically generates and saves a customized text-file completion certificate upon finishing the game.

## 🛠️ Tech Stack
- Language: C# (.NET)
- Concepts: Control flow, loops, methods/subroutines, file system interaction.
